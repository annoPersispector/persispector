## Warnings

- The AWS init SQL could not be applied verbatim on MySQL 8 utf8mb4 (ERROR 1071 key too long); the eventuate database was created with CHARACTER SET latin1 (patches/00-database-charset.sql).
- The AWS message table lacks message_partition required by eventuate-common-jdbc 0.21.0; every order creation failed until the column was added (C00, patches/01-schema-message-partition.sql).
- Kafka consumer auto-configuration was displaced by a verification-only in-process MessageConsumerImplementation (patches/NoKafkaConsumerAutoConfiguration.java) because Kafka/CDC are external services outside the allowed ports; the JDBC outbox producer path was unchanged.
- Only 2 of 74 targets (message.payload length and type) are reachable through the order-service public API; the remaining targets concern framework-generated values or tables used only by CDC/event-sourcing components.
